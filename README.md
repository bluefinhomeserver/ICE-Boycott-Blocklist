# ICE-Boycott-Blocklist
This is a Blocklist of all company sites in the ICE Boycott. This way, people get information without having to look into things themselves and can decide what they want to support

Everything so far is manually sourced from [The ICE List](https://theicelist.org/index.php/ICE_List:Boycott_list)

Import into uBlock Origin with this URL: https://raw.githubusercontent.com/bluefinhomeserver/ICE-Boycott-Blocklist/refs/heads/main/ICE-List/filterlist.txt

Ublock Origin Settings > Filter list > Scroll down > Import
